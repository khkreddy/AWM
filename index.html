Assessment World Model

A public, static demonstration of sheaf-aligned assessment data and deterministic retrieval. No model runs in this browser. Chemistry is the first subject with a curriculum map; a node id is enough to retrieve map + supplement + questions and typeset an exam paper.

Join key for chemistry: map.node.id = supplement.node_id = question.node_ids[]. Filter, sort by item_uid, optional seeded shuffle. Same query JSON → same paper.

Misconception prose, examiner comments, and source-paper crops are withheld. Cambridge item wording is for this working demonstration of retrieval, not a republished past-paper pack.
